# Local game JAR

Place the legally obtained NOM 1 J2ME file in this directory as game/nom1.jar.

The JAR is intentionally ignored by Git and must not be committed to this public repository.

Reference file analyzed for this port:

- MIDlet-Name: NOM (by GDC)
- MIDlet-Version: 1.0.25
- MIDlet-Vendor: Living Mobile
- MIDlet-1 main class: Nom1
- MicroEdition-Profile: MIDP-1.0
- MicroEdition-Configuration: CLDC-1.0
